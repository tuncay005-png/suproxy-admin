### CSS Variables for Theming

Tailwind CSS v4 and shadcn/ui use CSS variables for consistent theming:

```css
:root {
  --background: ...;
  --foreground: ...;
  --card: ...;
  --card-foreground: ...;
  /* etc */
}

.dark {
  --background: ...;
  --foreground: ...;
  /* dark mode values */
}
```

These are automatically generated by the shadcn/ui CLI.
